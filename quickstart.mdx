## Maak je 1e server

Ga naar: [https://panel.cristalcloud.nl](https://panel.cristalcloud.nl)&#x20;

Daar zie je als het goed is een inlogscherm als je nog niet ingelogd bent. Als je nog geen account hebt, klik je op: [Signup with Email](https://panel.cristalcloud.nl/auth/register), of op: [Authenticate with Discord](https://panel.cristalcloud.nl/auth/discord) .&#x20;

Dan kan je nu een account maken. Wanneer je bent ingelogd, kom je als het goed is op een scherm met geen enkele server. Dat komt omdat je nog geen server gemaakt hebt. Nu ga ik je uitleggen hoe je een server maakt.&#x20;

**Stap 1:**
Klik aan de zijkant op het winkelwagentje, dan kom je terecht in de store.&#x20;
![](/image.png)

Wanneer je daar bent, klik je op [Create](https://panel.cristalcloud.nl/store/create). Dan kom je op een pagina waar je de naam en beschrijving van je server kan instellen. Ook kan je de RAM, CPU load en disk instellen. Ik raad aan dat allemaal op default te houden. Let wel op dat je bij Deployment in moet stellen wat voor server je wilt maken. ![](/Schermafbeelding2025-01-13173835.png)

Bij Available Nodes moet je Node-1 selecteren, want er is momenteel geen andere node beschikbaar. Bij Server Nest kan je kiezen wat voor server je wilt. En bij Server Egg kan je het type nest selecteren.&#x20;

**Voorbeeld:**
Server Nest: Minecraft
Dan kan je dus bij Server Egg kiezen of je Minecraft Paper, Minecraft Vanilla, Minecraft Velocity of Minecraft Bedrock wilt als type server.&#x20;

Als je dat allemaal hebt gekozen, klik je op de groene knop: Create. Nu is je server gemaakt. Dan kan je weer terug gaan naar de hoofdpagina, en dan heb je als het goed is 1 server in de serverlijst staan.&#x20;
